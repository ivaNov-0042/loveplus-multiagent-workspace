## 流程链

逐段说明：当前在哪个页面、要做什么、注意什么。坐标见文末「坐标表」节。

### 1. 启动 → 标题画面

- 「違法な配信…」警告屏：A 键按住 ~120 帧（`buttons('1')`）推过。
- 标题画面（NEW ラブプラス+ logo + Touch Start）：**必须 `drag_path` 长按 `hold_frames=[200]`**，普通 `touch`（150/300 帧）不触发加载。
- 长按后进「データを読み込んでいます」→ 可能弹通信 ERROR / 追加データ 确认框（はい / いいえ）。
- 误入菜单第 4 项 `引継ぎツール` 会进说明页，触摸无反应，只能重启。

### 2. Main Menu（6 项）

- 第 1 项 ゲームスタート、第 6 项 データ管理（在底部）；竖排间距约 dump_y 40。
- **必须长按 ~150 帧**（`drag_path(points=[[x,y]], hold_frames=[150])`），tap 90 帧无效。
- 坐标表里 y=0.5 的旧记法是错的，别按旧值点。

### 3. オプション / データ管理

- 両页左下 戻る 回主菜单 `(0.047, 0.125)`。
- オプション 各子项坐标待标定；`セーブデータ削除` 危险勿点。
- データ管理 可输出存档；`戻る` 需长按，第一次可能不中（重试一次）。

### 4. データ選択（载入存档）

- 中央 DATA No.01 卡长按载入；载入前先读上屏存档信息：`データ更新`（日期）、`名前`、`経過日数 N日`。
- 左下 戻る `(0.044, 0.083)`；旧记 `(0.056, 0.867)` 落在右下空白，按了没反应。

### 5. 時計確認 → INFORMATION

- 时钟确认页 次へ（右下）→ 弹确认框 → はい 推进。
- INFORMATION 框 OK 是中央横长按钮，需长按 ~200 帧。
- 新游戏链上 INFORMATION 连续出现两次（時刻確認 + 通信礼仪）。

### 6. Profile 输入（プロフィール）

- 上屏自上而下 5 栏：苗字 → 名前 → 誕生日(月/日) → 血液型 → 出身地；当前栏青色高亮。
- 点当前栏 → 下屏弹输入板（默认手写板）→ 输入 + OK → 回表单页、聚焦下一栏。
- **每栏 OK 提交后输入板重置为手写板**，下一栏要重新切键盘（右上田字格 tab）。
- 输入机制（2026-10-16 实测）：
  - 左上 tab：铅笔 = 手写板，田字格 = 50音键盘（10 行 5 列，单页 `<1/1>`）。
  - 右栏勾选：かな = 平假名，カナ = 片假名，漢字 = 勾选后输假名自动弹汉字候选，小文字 = 小假名页。
  - `゛` 作用于前一个假名（す → ず）；`削除` = 退格；`クリア`（仅手写板）删上屏已提交的字；`棄る` = 清缓存 + 候选页，不动已提交文本。
  - 称呼栏（苗字呼び方 / 名前呼び方）**候补必选**，选完还要再点 OK。
  - 输入结果只看**上屏**（下屏只有输入板）→ 每次输入 u/b 成对截图。
  - 切 tab 前先 press → 截图验证 → 再 release（某些状态会误触退出读档）。
- 全字段填完 → 登録確認 はい `(0.266, 0.729)` → 新とわの駅，游戏正式开始。

### 9. 对话推进 / 選択支

- 推进用 **A 键**：`buttons('1')` 持帧 ≥60 → `buttons_off()`；每次点击/长按一律 ≥60 帧。
- 下屏右下 `‖ AUTO` 实测 `(0.256, 0.888)`：点亮也不会自动推进（疑似等语音播完），静置 30/60s 台词不变，仍靠 A 键。
- 全屏白/黑 = 转场中，要 20~60s；期间 A 无效，**不要据此判定卡死**（间隔截图多轮再下结论）。
- 選択支：选项文本在上屏，编号按钮 ①②③④ 在下屏最左列（部分被左缘裁切）；命中用 touch + release（≥1s），tap 无效。

## 按键位掩码

`buttons(hexmask)`：`bit i = NativeButton::Values(i)`（azahar 源码确认），与脚本 plan 掩码 OR；`buttons_off()` 清零。

| 键 | hex | 键 | hex |
| --- | --- | --- | --- |
| A | 0x001 | L | 0x100 |
| B | 0x002 | R | 0x200 |
| X | 0x004 | Start | 0x400 |
| Y | 0x008 | Select | 0x800 |
| Up / Down | 0x010 / 0x020 | Left / Right | 0x040 / 0x080 |

用法示例：A 键推进 `buttons('1')` 持 ≥60 帧 → `buttons_off()`。16 位完整表见坐标表节。
