# loveplus 工作日志 2026-10-14/15

## 目标

获取 New Love Plus+ 中 Siren14（ITU-T G.722.1 Annex C / Polycom）语音数据的解码方式。

## 今日完成

### 1. 工具链
- **3dstool 1.2.6**：源码编译成功（`tools/3dstool/bin/Release/3dstool`）。
- **gdb-multiarch 18.1**（ARM/ARMv7）：无 sudo，从 aliyun 镜像取 .deb 解包 +
  自建 `libipt.so.2` 桩 → `tools/bin/gdb-multiarch`。
- **venv**（`.venv/`）：capstone 5.0.7、pillow。

### 2. 资源提取（NLP+）
- 3dstool 提取 `main.cxi` → ExeFS(`code.bin` 4.2M) + RomFS(3808 文件)。
- 关键坑：3dstool 默认对 RomFS 做 AES-CTR 会破坏解密数据；
  改用 `dd` 按 NCCH 头 offset carve RomFS 再 `-t romfs` 解包成功。
- 归档到 `data/loveplus/nlp_plus/`：
  `audio/Siren14Voice.spp`(656M)、`Siren14voice.bin`(724K)、`Siren14Voice.dpb`(16B)、
  `audio/bcsar/`(5 个 .bcsar + csid)、`audio/stream/`(492 个 .bcstm)、`code.bin`。
- 中间文件全部清理。

### 3. 无头 azahar（Citra fork）—— 已跑通并能调试
详见 `memory/loveplus/headless_azahar.md`。要点：
- 自建最小前端 `src/citra_headless/`（软件渲染器 + 空 EmuWindow），无 Qt/SDL 依赖。
- 两处绕过：NCCH `no_crypto` 补丁（ROM 副本）；`lle_modules` 映射填充。
- **游戏无头启动成功**（`nlpp`，00040000000F4E00），可长时间运行（跑到 emu 54s）。
- **截图可用**：`--dump-every N --dump-prefix P` 导出 PPM，已看到 KONAMI 启动 logo。
- 因 `ptrace_scope=2`，走 azahar **GDB stub(TCP)**；自研 RSP 客户端可枚举 17 线程、
  读寄存器/内存、单步、断点，**断点实测命中** `0x00122a50`。

### 4. Siren14 数据结构（静态确认）
- `Siren14voice.bin` = 92655 组小端 (offset,size)，精确铺满 `.spp`（sum=文件大小）。
- 所有 size 均为 **46 字节整数倍**（min=46）→ 每条语音 = N×46B 帧。
- `.dpb` = `{0x17=23,1,1,0x10}`。
