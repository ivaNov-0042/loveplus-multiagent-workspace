**指纹对齐（口径固定，勿改）**：对同一次请求，
`9router.promptTokens = message.tokens.input + message.tokens.cache.read − 2000`，
`9router.completionTokens = message.tokens.output + message.tokens.reasoning`，
`reasoning_tokens` 逐字节相同。

**时间相关性（最硬的一条）**：mimo 行只出现在请求 `cbcn/hy3`、`cbcn/hy4-preview` 的时段；
纯 `glm-5.3-flash` 的 04:00–07:00 一行为 0；08:13 切回 hy3 后立刻又出现 40 行。

> 注意：指纹匹配要**从「行→消息」方向**用（一行对一消息）。反向会重复计数——

## 二、机制（9router 侧）

- provider 注册表里 `oc` = **OpenCode Free**：`{id:"opencode", alias:"oc", category:"free",
  noAuth:true, transport:{baseUrl:"https://opencode.ai", forceStream:true}}`。
- 免费兜底模型在代码里**硬编码**为 `oc/mimo-v2.6-flash-free`（capacity-adapter 助手池为空时的
  默认值；dashboard 文案即 "will fallback to oc/mimo-v2.6-flash-free"），README 的
  "Auto fallback — Subscription → Cheap → Free" 与 UI 文案「按订阅、低价和免费层级路由，自动回退」同源。
- chat 入口：`v = t8(body)`（判定所需能力，如 vision/reasoning）→ `R8([model], v, settings)`
  扩充候选（capacity adapter）→ 候选 >1 时打印 `Capacity adapter for [...] on "…" → trying …`
  并交给 combo runner（内含 `COMBO auto-switch` / `FALLBACK ⇄ ACC:` 分支）。

## 三、两个会误导判断的坑（均已实测复现）

### 坑 1：9router 对 opencode 的流量严重少记，用量页/日志**不能当全部请求看**

9router 只在**客户端把 SSE 读到底**时才写 `usageHistory`；opencode（ai-sdk）拿到 `usage`
分片就断开连接，于是不落库。实测（2026-10-16 10:1x CST）：

- `opencode run -m 9router/cbcn/glm-5.3-flash "…"`（直连 9router）→ **新增 0 行**；
- 同一请求（含 opencode 的 12 个 tools、`store:false`、`stream_options`、opencode 专有 header）
  经 curl 或经本地反向代理转一手 → **1 行**；
- 裸 socket 模拟：读到 `"usage"` 立即 close → **0 行**；继续读到 `data: [DONE]` → **1 行**。

所以「opencode 记 1464 条 / 9router 记 102 行」的 7% 是记录机制造成的，
**不是**「流量去了别的 9router 实例」。推论：96 行 mimo 属于 9router 主动改派时留下的内部记录，
可当「**至少** 96 次改派」的下限；真实占比无法由该表反推。

### 坑 2：opencode 免费层级只接受「来自 opencode 的请求」

直接从 9router 打 `oc/mimo-v2.6-flash-free` 返回
`403 FreeTierError: OpenCode's free tier can only be used from within OpenCode.`
即该兜底链能成功，依赖客户端（opencode）header 被 9router 透传（此条为**推断**，未逐项验证）。

# 9router 窗口内各 provider/model 计数
python3 -c "
import sqlite3,datetime,collections
c=sqlite3.connect('file:$HOME/.9router/db/data.sqlite?mode=ro',uri=True)
h=collections.Counter()
for ts,p,m in c.execute(\"select timestamp,provider,model from usageHistory where timestamp>='2026-10-15T14:00:00'\"):
    t=datetime.datetime.strptime(ts[:19],'%Y-%m-%dT%H:%M:%S')+datetime.timedelta(hours=8)
    h[(t.strftime('%m-%d %H'),p,m)]+=1
[print(k,v) for k,v in sorted(h.items())]"
